# smart-food-thermometer
## Wifi-Enabled Food Thermometer intended for foods with long cook times (roasts, smoked meat, stews, ...)

The user has access to a web interface allowing for remote use of the product by:

-displaying the thermometer's current temperature

-being able to set a target temperature with notifications

-being able to calibrate a malfunctioning NTC thermistor if needed

### <ins>Components used:</ins>

-ESP32 

-ADS1115 ADC

-0.96' OLED display

-3.5mm jack breakout board

-Switch
